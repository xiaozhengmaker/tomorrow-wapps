# DESIGN.md — 明日清单

> 这份文件的用途：让任何接手的人（或 AI）在读代码之前，先知道这个产品**长什么样、为什么这么长**。
> 改任何界面前先读这里；改完如果视觉规则变了，回来同步更新。
> 写法参考 [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md)。

---

## 1. 一句话定位

一个在微信里记录「今天/某天要做什么」的纸质手账。
**气质参考《旅行青蛙》**：米绿纸底、手绘线条、圆润厚实、安静不吵闹。

不是效率仪表盘，不是 To-do 工具的重工业风。它应该像一页真正的纸。

## 2. 三条不可动的原则

1. **纸张而非玻璃**。没有毛玻璃、没有霓虹、没有高饱和渐变。所有面都是"一张纸"。
2. **圆润且厚实**。圆角一律偏大；按钮有实体厚度（底部实心阴影），按下去会真的陷进去。
3. **安静**。不用红色警示、不用弹跳动画催人。进度落后也只用陈述句。

## 3. 颜色

主色是**苔绿**，辅色是**暖橙**（只用于"重要/卡住"这类需要看一眼的地方）。背景是带黄的米绿，不是纯白。

## 4. 字体与字号

**只用系统字体**，不加载自定义字体（小程序要域名+备案，不值得）。
靠字重、字距、行高营造手写感。

```css
font-family: -apple-system, BlinkMacSystemFont, "PingFang SC", "Helvetica Neue",
  Helvetica, "Microsoft YaHei", sans-serif;
```

| 用途 | 字号 | 字重 | 字距 |
| --- | --- | --- | --- |
| 页面大标题 | 44–46rpx | 700 | 1rpx |
| 首页 hero | 60rpx | 700 | 1rpx |
| 卡片标题 | 30rpx | 600 | 0 |
| 正文 / 事项标题 | 29–31rpx | 400 | 0 |
| 说明文字 | 24–25rpx | 400 | 0 |
| 小标签 / 数字角标 | 20–22rpx | 400 | 0 |
| 英文 eyebrow | 21rpx | 400 | **7–8rpx**（拉开才有版式感） |

行高：正文 1.55，多行段落 1.6–1.75。中文不要低于 1.5。

## 5. 圆角 / 阴影 / 厚度

| 元素 | 圆角 |
| --- | --- |
| 卡片 | 34rpx |
| 主按钮 | 30rpx |
| 次按钮 | 26rpx |
| 小按钮 / 标签 | 12–20rpx |
| chip / 日期胶囊 | 28rpx（做成胶囊） |

**阴影一律偏绿、偏软**，不用黑色投影：

```css
box-shadow: 0 10rpx 28rpx rgba(86, 116, 66, 0.09);   /* 卡片 */
```

**按钮厚度是这套设计的关键**：底部一层实心阴影，按下时整体下沉。

```css
/* 常态 */
box-shadow: 0 8rpx 0 #567749, 0 16rpx 28rpx rgba(86, 116, 66, 0.24);
/* 按下 */
transform: translateY(6rpx);
box-shadow: 0 2rpx 0 #567749, 0 8rpx 16rpx rgba(86, 116, 66, 0.2);
```

## 6. 组件规格

### 主按钮 `.btn-primary`
- 高 98rpx，圆角 30rpx，字 31rpx/600，字距 3rpx
- 渐变见上，文字 `#fbfdf6`
- 禁用：面 `#dfe8ce`、字 `#9caa90`、厚度阴影 `#d2ddbf`

### 次按钮 `.btn-ghost`
- 高 84rpx，面 `#f7faf0`，描边 2rpx `#d9e3c9`，厚度阴影 `0 5rpx 0 #e2ead4`
- 按下下沉 4rpx

### 卡片 `.card`
- 面 `#fbfcf3`，描边 **2rpx** `#dde6cf`（1rpx 会显得太脆）

### 标签 `.tag`
- 字号 21rpx，内距 4rpx 16rpx，圆角 12rpx
- 五类固定色：工作=钢蓝 `#e4edf6/#4a6f96`、生活=米黄 `#f7edd8/#9a7433`、健康=草绿 `#e6f2e4/#4f7a52`、学习=藕紫 `#efe9f6/#6f5595`、其他=灰绿 `#edf0e4/#71806a`

### 进度状态色（`.st-*`）

| 状态 | 底 | 字 |
| --- | --- | --- |
| 卡住了 | `#f7ecdd` | `#b06a45` |
| 快好了 | `#e6f2e4` | `#4f7a52` |
| 进行中 | `#e4edf6` | `#4a6f96` |
| 刚起步 | `#e9eef5` | `#5b7089` |
| 还没动 | `#eef1e5` | `#8d9b82` |
| 有进展 | `#efe9f6` | `#6f5595` |

### 时间轴
- 左列时间宽 104rpx，右对齐
- 中间竖线 2rpx `#dee7cf`，节点是 20rpx 空心圆，描边 5rpx `#c6d3b2`、内白
- 每项右侧一张卡片，间距 20rpx

## 7. 布局与间距

- 页面左右内距固定 **32rpx**，底部 **120rpx**（给 tabBar 留白）
- 卡片之间 **22rpx**
- 卡片内部 **26rpx**
- 字号与间距用 2rpx 的倍数，不要出现 15rpx、27rpx 这种

## 8. 动效

少而短，全部 ≤ 300ms。

| 场景 | 效果 |
| --- | --- |
| 按钮点击 | `translateY(6rpx)` + 阴影收缩，**不加缩放** |
| 卡片点击 | 背景变 `#f8fbee` |
| 叶子装饰 | 4.5s 缓动摇摆（`.leaf-sway`） |
| 底层弹窗 | 从下往上 220ms，`cubic-bezier(.2,.8,.3,1)` |

不用的：弹跳、旋转、闪光、数字滚动。

## 9. 文案语气

**中性陈述，不夸不骂不催。**

| ✅ | ❌ |
| --- | --- |
| 计划 3 项，完成 1 项（33%）。 | 今天只完成了一点点，加油！ |
| 没打勾的是：找素材、健身。 | 你今天有点懈怠哦 |
| 还没动 | 今天又躺平了 |

具体可做的动作，用动词开头、一句话能读完：
「列出这件事必须回答的 3 个问题」「先写最丑的一版，中途不许回头改」

按钮文字用**动作 + 结果**，不用「提交」「确定」这种系统词：
`拆一下` / `拆一下` / `排进明天` / `生成评估` / `开始计时`

## 10. 装饰

只用 CSS 画的极简形状，不引外部图片：

```css
/* 叶子：一个圆角朝对角的矩形 */
.leaf {
  width: 34rpx; height: 34rpx;
  background: #b9cf9e;
  border-radius: 0 100% 0 100%;
  transform: rotate(-38deg);
}
```

`🌿`、`🐸` 这类 emoji **不要用**——各端渲染不一致，会破坏手绘感。

## 12. 自检清单

改完界面，过一遍：

- [ ] 有没有出现纯黑 `#000` 或纯白 `#fff`？
- [ ] 阴影是偏绿的软阴影，还是黑色硬投影？
- [ ] 按钮按下去有没有"陷进去"的感觉？
- [ ] 新加的字号是不是 24 / 29 / 31 / 44 这一档？间距是不是 2rpx 倍数？
- [ ] 文案有没有混进"加油""建议""太棒了"？
- [ ] 圆角是不是都 ≥ 12rpx？
