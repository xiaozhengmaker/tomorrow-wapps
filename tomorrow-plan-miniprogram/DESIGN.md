## 1. 定位

一个在微信里记录「某天要做什么」的规划器。
视觉参考 [Joi（recent.design）](https://recent.design/i/8fcukfl-joi)：**纯白、无阴影、超大字号、图标+标题+右侧时间的平铺列表、虚线分隔、淡彩胶囊**。

不是卡片墙，不是仪表盘。是一张干净的日程表。

## 2. 三条原则

1. **白到底**。背景纯白，没有纹样、没有渐变、没有毛玻璃。层次靠留白和虚线，不靠投影。
2. **字要大、要重**。标题 800 字重、负字距；这是整套风格最显眼的特征。
3. **颜色只标状态**。蓝=行动/进行中，橙红=卡住/重要，绿=完成，紫=学习。没语义的地方一律黑白灰。

## 4. 字体

系统字体，靠字重拉开层次。

| 用途 | 字号 | 字重 | 字距 |
| --- | --- | --- | --- |
| 页面主标题 | 56–58rpx | **800** | -1rpx |
| 首页 hero | 60rpx | **800** | -1rpx |
| 区块标题 | 44rpx | 800 | -0.8rpx |
| 列表项标题 | 32rpx | 600 | -0.3rpx |
| 正文 | 29–31rpx | 400 | 0 |
| 时间 / 说明 | 22–24rpx | 400–600 | 0 |
| 标签 | 21rpx | 700 | 0 |
| 英文 eyebrow | 21rpx | 500 | 7rpx |

**负字距是大标题的关键**，别用默认字距。

## 5. 圆角与投影

| 元素 | 圆角 |
| --- | --- |
| 按钮 / 标签 / chip / 日期 | **999rpx（胶囊）** |
| 卡片 | 24rpx |
| 进度块 | 14rpx |

**全站不用投影。** 唯一的例外是没有例外——层次靠留白、虚线和字号。

## 6. 组件

- **主按钮**：高 100rpx、胶囊、`#0a84ff` 纯色、白字 32rpx/800。按下 `scale(0.972)` + 透明度 .92，**不做下沉重影**。
- **次按钮**：`#f2f2f7` 底、黑字 600、胶囊、无描边。
- **危险按钮**：`#ffede6` 底、`#ff3b30` 字。
- **标签**：胶囊 + 淡彩，21rpx/700。
- **列表行**：时间（左，800，27rpx）+ 标题（32rpx/600）+ 底部 `2rpx dashed #ececf1`。**行本身没有背景、没有卡片**。
- **勾选圈**：2rpx `#d1d1d6` 描边，完成变 `#0a84ff`。
- **进度块**：`#f2f2f7` 圆角块，24rpx 字。

## 7. 动效

Joi 的动效是**轻、快、短**：位移 20rpx 以内，时长 160–360ms，全部用 `cubic-bezier(.2,.8,.3,1)`。

| 场景 | 效果 |
| --- | --- |
| 列表入场 | `rise`：`translateY(20rpx)` + 透明度 0→1，**每行延迟 40ms 依次升起**（`.stagger > view`） |
| 按钮按下 | `scale(0.972)` + 透明度 .92 |
| chip / 日期选中共 | 背景与颜色 180ms 过渡，按压缩到 0.95 |
| 勾选圈 | 按压缩 0.9，勾中时背景 180ms 变蓝 |
| 弹层 | 220ms 从下滑入、遮罩淡入 180ms |
| 结果卡出现 | `popIn`：scale 0.9 → 1.03 → 1 |

不用的：弹跳、旋转、长时长漂移、视差。

## 8. 文案语气

**中性陈述，不夸不骂不催。**

| ✅ | ❌ |
| --- | --- |
| 计划 3 项，完成 1 项（33%）。 | 今天只完成了一点点，加油！ |
| 没打勾的是：找素材、健身。 | 你今天有点懈怠哦 |
| 还没动 | 今天又躺平了 |

按钮用「动作 + 结果」：`拆一下` / `排进明天` / `生成评估`。

## 9. 不用什么

- ❌ emoji 当图标（各端渲染不一致）
- ❌ 投影、渐变、毛玻璃
- ❌ 背景纹样、点阵、噪点
- ❌ 红色警示块（重要也用淡彩，不用大色块压人）

## 11. 自检清单

- [ ] 背景是不是纯白？有没有残留纹样/渐变？
- [ ] 大标题是 800 字重 + 负字距吗？
- [ ] 所有按钮/标签是胶囊吗？
- [ ] 有没有不小心加了投影？
- [ ] 列表行之间是虚线，还是被包成了一张张卡片？
- [ ] 列表入场有没有依次升起的错落感？
- [ ] 文案里有没有「加油 / 建议 / 太棒了」？
